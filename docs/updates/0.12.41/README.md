# VitarenewFlow 0.12.41

## Neuerungen

- Emulatorspiele werden in typischen SD-Spieleordnern und ihren Unterordnern gefunden.
- Die Bibliothek bietet Platz für bis zu 1536 Spiele verschiedener Systeme.
- Desktop-Verwaltung für macOS und Linux direkt im Menü auf die SD laden.

## What's new

- Emulator games are found in common SD game folders and their subfolders.
- The library supports up to 1536 games across different systems.
- Download the macOS and Linux desktop manager to the SD card from the menu.
