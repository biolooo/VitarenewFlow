# VitarenewFlow 0.12.23

Fehlende Emulatoren werden beim Spielstart verständlich benannt. Mit A oder Touch geht es direkt zur passenden Einrichtung, mit B zurück zur Library.
Ungültige Emulator-Dateien bieten Neuinstallation an. Nicht lesbare SD-Dateien, fehlende/unvollständige ROMs und zu lange Spielpfade erhalten eigene Hinweise. Technische Details bleiben im Log.
Enthält weiterhin alle sechs Emulator-Downloads, Desktop-Verwaltung sowie die Audio-Verbesserungen aus 0.12.22.

## Test auf der Konsole
- N64-Spiel ohne Emulator starten: Hinweis auf DaedalusX64 und Einrichtung erscheint.
- B kehrt ohne Download zurück; A/Touch öffnet den N64-Download.
- Emulator installieren und dasselbe Spiel erneut starten.
- Ein bereits funktionierendes anderes Spiel starten.
- Hinweise und Buttons auf Deutsch und Englisch prüfen.

Native Build und lokale Fehlerfalltests bestanden. Hardware-Abnahme steht aus.
