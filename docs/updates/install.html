VitarenewFlow installieren

Testversion 0.12.31 · Für eine bereits gemoddete Konsole mit Universal-Updater.

  1. Universal-Updater öffnen.
  2. Einstellungen → UniStore auswählen → + → QR-Code.
  3. Diesen QR-Code scannen und Store hinzufügen.
  4. VitarenewFlow (Test) auswählen und Installieren / Install starten.
  5. Universal-Updater schließen und Flow im HOME-Menü öffnen.

Installiert Flow und das HOME-Symbol. GB/GBC/GBA, Nintendo 64, DS, SNES, NES und Virtual Boy lassen sich anschließend unter Menü → Spiele verwalten → Emulatoren direkt herunterladen und einrichten. Die Windows-Verwaltung lässt sich dort unter Desktop-Verwaltung auf die SD herunterladen. Klicks sind fest eingebaut; fehlende Audio-Firmware wird lokal auf der Konsole vorbereitet. Die ursprünglichen Emulator-Lizenzen bleiben erhalten. Keine Spiele, BIOS oder Spielstände enthalten. Kein PC-Setup nötig.
