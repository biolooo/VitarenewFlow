# Optionale Plan-Konvention

Ein Plan gehört nur zu einem ausdrücklich beauftragten Vorhaben. Format: Ziel und Nichtziele; gesicherter Ausgangsstand; Dateizuständigkeit; kurze Schritte; Risiken/Rückweg; lokale Nachweise; gesonderte Konsolenabnahme; aktueller Haltpunkt.

Der Orchestrator führt höchstens einen aktiven Integrationsplan und verweist auf `docs/STATUS.md` für den Projektstand. Ein Plan delegiert, veröffentlicht oder aktiviert keine Backlogaufgabe von selbst. Für die Migration gilt zunächst nur der lesende Auftrag in `docs/HANDOFF.md`.
